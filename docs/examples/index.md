# Examples

Runnable examples live in [`examples/snippets`](./snippets/) and are executed without network access by `composer docs:examples`.

## Guides

- [API integration](./api-integration): compose helper functions and clients.
- [Authentication](./authentication): bearer tokens and request headers.
- [Error handling](./error-handling): distinguish response status from exceptions.
- [Async patterns](./async-patterns): Matrix promise helpers and their limits.
- [File handling](./file-handling): multipart upload guidance.

The guides use illustrative endpoint URLs where a working API is required. Only the linked snippet files are executed by the offline example check.
