What if writing an HTTP request in PHP felt a little more like JavaScript's `fetch()`?

I've been maintaining **Fetch PHP**, an open-source HTTP client built on Guzzle.

It offers a familiar `fetch()` entry point, with PHP-oriented configuration, retries, streaming, optional async workflows and PSR interoperability.

I'm **not** trying to replace Guzzle or Laravel's HTTP client. I wanted an approachable, framework-independent option for PHP developers who also work in JavaScript.

The API is JavaScript-inspired, not a browser Fetch polyfill.

GitHub: https://github.com/Thavarshan/fetch-php
Docs: https://fetch-php.thavarshan.com/

If you build integrations in PHP, I'd genuinely appreciate feedback: what's missing, and where would a minimal example help?
